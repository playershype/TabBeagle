## Security scope and interpretation

The produced image/code asset is the **actual Expo JavaScript export from the same unmodified source/lockfile as the last signed HTTPS QA APK**. The source map is evidence for JavaScript inclusion only. It is NOT a binary audit of Android native dependencies, APK resources, AAR libraries or a proof of invulnerability. The `@expo/cli` module mapped into the bundle may be a runtime helper and does not mean the full CLI package is included.

No `npm audit` advisory was suppressed or marked resolved as a consequence of this exercise. **All 36 npm audit findings remain open on the exact HTTPS QA app until patched or formally risk-accepted**, and any signed-JWT cross-tenant HTTPS certification remains separately NOT EXECUTED.
